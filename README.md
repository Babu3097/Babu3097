## What I do

1. **Define the requirement** — translate a business need into a concrete, testable spec before any build starts.
2. **Direct the build** — use Claude Code as the implementation layer, under my review at every step.
3. **Design the guardrails** — approval workflows, fail-safe defaults, and review checkpoints so AI output never ships unchecked.
4. **Validate against outcomes** — test the result end-to-end and report on what actually changed.
